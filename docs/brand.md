# KAZAM 视觉身份

产品名：**KAZAM**  
呼号：**KZ-AM**  
一句定位：**载波电台** — 独立桌面播放器，晚间 FM 控制室的温度。

## 材料

主标是黑底唱片上的几何 **K**（`src/renderer/brand/mark.jpg`）。字标用 Fraunces + 代码绘制，不把 “KAZAM” 烧进位图。

调色：灯黑 `#0C0B0A` / 暖象牙 `#F4EDE1` / 琥珀信号 `#E8A84A` / 靛蓝槽纹 `#2A3A52`。白日模式是牛皮纸 `#EDE4D4` 与焦橙 `#C45C26`。

字体：Fraunces（标题）+ IBM Plex Sans（界面）+ IBM Plex Mono（呼号、时钟、序号）。中文回落到苹方 / 微软雅黑。

运行入口：`cd kazam && npm run dev`。这是第一方 UI，不再往官方 hashed asar 上贴皮。
